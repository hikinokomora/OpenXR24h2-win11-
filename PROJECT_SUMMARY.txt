📋 PROJECT OVERVIEW
═══════════════════════════════════════════════════════════════════════════════

PURPOSE:
  Restore OpenXR functionality on Windows 11 24H2 and newer versions where
  Microsoft removed the built-in Mixed Reality Portal and Windows Mixed 
  Reality components.

SOLUTION:
  Configure Windows registry to enable OpenXR runtime integration with
  third-party VR systems (primarily SteamVR).

TARGET USERS:
  - VR enthusiasts using Windows 11 24H2
  - Developers working with OpenXR applications
  - VR headset owners (Valve Index, HTC Vive, Meta Quest, etc.)
